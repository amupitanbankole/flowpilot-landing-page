# FlowPilot Landing Page

A polished conversion-focused AI SaaS landing page concept created as a portfolio case study.

## Design objective
Communicate product value immediately, establish trust through product UI and social proof, explain the workflow in three steps, and drive visitors toward a free trial.

## UX decisions
- Clear primary CTA above the fold
- Product UI shown immediately to reduce ambiguity
- Short sections with strong visual hierarchy
- Social proof before feature exploration
- Repeated CTA at the end of the journey
- Responsive mobile layout

## Stack
HTML5 · CSS3 · Vanilla JavaScript

## Portfolio note
FlowPilot is a fictional brand created to demonstrate landing-page design, conversion thinking, visual hierarchy, and responsive front-end implementation.
